# DIY Drone

A team learning project about designing and building a remotely controlled drone with FPV, onboard AI and room for future improvements. The team will design the frame and electrical system, perform the calculations, choose components and write its own project plan.

The current direction includes ArduPilot, a Raspberry Pi 5 and possible Pico sensor/I/O controllers, with size and implementation details still flexible.

## Learning approach

The assistant acts as a teacher: explain concepts, guide calculations, help develop ideas and perform deep research on the specific topic requested. The user and team own the design decisions and implementation.

Project-specific instructions are in [AGENTS.md](AGENTS.md). User-stated goals and tentative technical preferences are retained in [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md).

The previous assistant-generated plans and engineering studies have been removed at the user's request. Their numerical proposals are not finalized project specifications. Future plans, notes and code will be developed by the team.
